# 🍽️ بوت حجز طاولة مطعم
### ثناء | thanaa.codes

بوت يحجز طاولة في المطعم بسهولة، يختار نوع الطاولة واليوم والوقت، ويأكد الحجز.

## ✨ وش يسوي؟
- يعرض 4 انواع طاولات: لشخصين، لـ 4 اشخاص، لـ 6 اشخاص، VIP
- يخلي الزبون يختار اليوم والوقت المناسب
- يستلم اسم الزبون ورقم جواله وعدد الاشخاص
- يطبع تأكيد حجز كامل بالسعر

## 🚀 كيف تشغليه؟
python restaurant-table-booking-bot.py

## 💰 السعر
2500 ريال سعودي - نسخة كاملة للمطاعم

## 📦 مثال على الحجز
الطاولة: طاولة لـ 4 اشخاص
اليوم: الجمعة
الوقت: 8 مساء
السعر: 80 ريال
